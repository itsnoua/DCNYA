# نظام لوحة قياس الامتثال - AseerComplianceV2

![Dashboard Preview](frontend/assets/images/aseer_logo.png)

نظام متقدم لإدارة ومراقبة امتثال المباني في منطقة عسير باستخدام التقنيات الجيومكانية (GIS). يوفر النظام رؤية تحليلية دقيقة لنسب الإنجاز ومطابقة الشهادات مع الأصول العقارية على الخريطة.

## نظرة عامة على المشروع
المشروع عبارة عن منصة متكاملة تتكون من:
1. **واجهة أمامية (Frontend):** مبنية باستخدام Vite و Javascript، وتعتمد على MapLibre GL لتمثيل البيانات المكانية ثلاثية الأبعاد.
2. **نظام خلفي (Backend):** مبني باستخدام FastAPI (Python) لمعالجة البيانات الضخمة وتوفير واجهات برمجة التطبيقات (APIs).
3. **قاعدة بيانات مكانية:** PostgreSQL مع إضافة PostGIS لتخزين ومعالجة البيانات الجغرافية.

## المميزات الرئيسية
- **تمثيل ثلاثي الأبعاد (3D):** عرض المباني بارتفاعات واقعية وتلوينها بناءً على حالة الامتثال.
- **تصفية ديناميكية:** إمكانية الفلترة حسب (المرحلة، البلدية، الشارع).
- **مؤشرات الأداء (KPIs):** عرض فوري لإجمالي الشهادات، المباني المستهدفة، ونسبة التغطية.
- **تحليل الفجوة المكانية:** تحديد الشهادات غير المرتبطة بمباني بدقة عالية.
- **خرائط حرارية ونقاط تفاعلية:** عرض مواقع صدور الشهادات وتحديثها لحظياً.
- **تتبع النمو:** رسوم بيانية توضح معدل الإنجاز الأسبوعي مقارنة بالفترات السابقة.

## المتطلبات التقنية
- **Node.js** (للواجهة الأمامية)
- **Python 3.9+** (للنظام الخلفي)
- **PostgreSQL / PostGIS** (قاعدة البيانات)

## إعداد وتجهيز النظام

### 1. إعداد قاعدة البيانات (PostgreSQL + PostGIS)
يجب إنشاء قاعدة بيانات وتفعيل الإضافة المكانية عليها:
```sql
CREATE DATABASE gis_db;
-- تفعيل الإضافة المكانية
CREATE EXTENSION IF NOT EXISTS postgis;
```

### 2. تشغيل النظام الخلفي (Backend)
```powershell
cd backend
pip install -r requirements.txt

# تنفيذ التهجيرات (Migrations) لإنشاء الجداول
alembic upgrade head

# تشغيل خادم FastAPI
uvicorn app.main:app --reload --port 8000
```

### 3. تشغيل الواجهة الأمامية (Frontend)
```powershell
cd frontend
npm install
npm run dev
```
سيكون النظام متاحاً على الرابط: `http://localhost:3000`

## كيفية استخدام لوحة القياس
1. **تبديل المراحل:** استخدم التبويبات في أعلى الصفحة للانتقال بين مراحل المشروع المختلفة.
2. **الفلترة المكانية:** يمكنك اختيار "بلدية" محددة أو "شارع" معين من القائمة المنسدلة للتركيز على منطقة معينة.
3. **التنقل في الخريطة:**
   - **التقريب (Zoom):** لمشاهدة تفاصيل المباني.
   - **الإمالة (Tilt):** لرؤية المباني بشكل ثلاثي الأبعاد (استخدم زر الفأرة الأيمن مع السحب).
4. **قراءة العداد:** يوضح العداد الكبير نسبة التغطية الكلية في المنطقة المختارة مع تقييم وصفي (ممتاز/متوسط/ضعيف).
5. **الرسوم البيانية:** توضح التطور الأسبوعي في إصدار الشهادات لمتابعة وتيرة العمل.
